### Searching
- **Linear Search**: A straightforward search method through all elements.
- **Binary Search**: A more efficient search algorithm that requires sorted data.

### Sorting
- **Bubble Sort**: A simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.
- **Insertion Sort**: Builds a sorted array by repeatedly taking the next element and inserting it into the correct position.

### Complexity Analysis
- Understanding big-O notation and common growth functions:
  - Constant: O(1)
  - Logarithmic: O(log n)
  - Linear: O(n)
  - Linearithmic: O(n log n)
  - Quadratic: O(n²)
  - Cubic: O(n³)
  - Polynomial: O(n^k) (k is a constant)
  - Exponential: O(2ⁿ), O(cⁿ) (c is a constant)
  - Factorial: O(n!)

### Important Big-O Relationships
- Relationships among functions:
  - log₂n and n log₂n
  - log₂n and n¹/₈
  - (log₂n)⁴ and n
  - n log n and n² 
- Example relations include:
  - log₂n = O(n), reverse not true
  - log₂n and log_b(n) are both O(log n)

### Example Problem: Maximum Subarray
- **Problem Statement**: Find indices i and j (1 ≤ j ≤ i ≤ n) such that the sum of elements from S[j] to S[i] is maximized.  
  - Example input: n = 12; S = [4, -7, 4, 0, 5, -8, 13, -2, 4, 6, -6, 2].
  - Maximum sum of 22 found for j = 3 and i = 10.

### Solutions
1. **Solution 1: Brute Force Approach**
   ```plaintext
   procedure MaxSum1(S, n)
       max := 0
       for i := 1 to n do
           for j := 1 to i do
               sum := 0
               for k := j to i do
                   sum := sum + S[k]
               if sum > max then
                   max := sum
       return(max)
   ```
   - Time Complexity: O(n³).

2. **Solution 2: Avoid Re-computation**
   ```plaintext
   procedure MaxSum2(S, n)
       max := 0
       for i := 1 to n do
           for j := 1 to i - 1 do
               sum(j, i) := sum(j, i - 1) + S(i)
               if sum(j, i) > max then
                   max := sum(j, i)
           sum(i, i) := S(i)
           if sum(i, i) > max then
               max := sum(i, i)
       return(max)
   ```
   - Time Complexity: O(n²) using O(n²) space for storage.

3. **Solution 3: Fast Updating (Dynamic Programming)**
   ```plaintext
   procedure MaxSum3(S, n)
       max := S(1); 
       sum := S(1);
       for i := 2 to n do
           if sum > 0 then
               sum := sum + S(i)
           else
               sum := S(i)
           if sum > max then
               max := sum
       return(max)
   ```
   - Time Complexity: O(n) with a single for-loop.

### Problem-Solving Tips
- Fully understand the problem.
- Solve it “by hand” for validation.
- Develop an initial straightforward algorithm.
- Critically evaluate solutions to improve efficiency.
- Look for redundant computations that can be optimized.
