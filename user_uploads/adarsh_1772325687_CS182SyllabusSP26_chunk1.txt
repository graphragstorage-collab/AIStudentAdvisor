### Course Description
This course provides an introductory coverage of discrete mathematics tools and reasoning essential for computer science. Topics include:
- Logic
- Proof Methods
- Functions, Sets, and Relations
- Number Theory
- Algorithms
- Induction
- Counting
- Probability
- Graph Theory
- Finite-State Automata
- Regular Expressions
- Context-Free Languages
- Turing Machines
- Computability  

### Learning Outcomes
Students will demonstrate:
- Application of discrete-math foundations to solve complex problems.
- Ability to analyze algorithms using Big-O/Θ/Ω notation.
- Implementation of graph-theoretic algorithms for practical applications.

### Required Text
