### Course Description
Introduction to discrete mathematics tools for computer science, covering:
- Logic
- Proof methods
- Functions
- Sets
- Number theory
- Algorithm analysis
- Induction
- Counting
- Probability
- Graph theory
- Finite-state automata
- Regular expressions
- Context-free languages
- Turing machines
- Computability

### Learning Outcomes
- Apply discrete mathematics principles
- Analyze algorithm complexity (Big O, Θ, Ω)
- Solve graph-theory problems

### Required Text
- K. Rosen, *Discrete Mathematics and Its Applications* (7th/8th ed.) with online student resources
