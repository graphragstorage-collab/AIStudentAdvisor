### Schema Specifications

**Database Domains for Columns**  
Each column of every table has specified allowable values according to the schema:

- `Number`: Must be a 3-digit number
- `Owner`: Must be a 30-character string
- `Type`: Must be “checking” or “savings”

The set of allowable values for a column is referred to as the domain of the column.

### Data Model Definition

**What is a Data Model?**  
A data model is a notation for describing data or information. The description typically consists of three parts:
1. **Structure of the data**
2. **Operations on the data**: Limited set of queries (operations that retrieve information) and modifications (operations that change the database).
3. **Constraints on the data**: Ways to outline limitations on what the data can be, often stemming from real-world application requirements.

### Relational Data Model Popularity

The relational data model is the most widely used in database systems, including:
- Oracle
- MySQL
- MS SQL Server
- PostgreSQL
- IBM DB2
- SQLite
- Microsoft Access

For additional details, you can check: [DB-Engines Ranking](https://db-engines.com/en/ranking)

### Summary

- A data model is an abstract framework that categorizes elements of data and standardizes their relationships to properties of real-world entities.
- Several types of data models exist including Relational and Graph models.
- Our focus is primarily on the relational model, which structures data as relations (tables) and defines a limited set of operations (query and modification) for data interaction.
