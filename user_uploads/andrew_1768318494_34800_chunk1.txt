### Course Description
This course introduces fundamental concepts of database management, primarily using the relational model. Key topics include:
- Schema design and refinement
- Query languages
- Database application development
- Transactions and concurrency control
- Overview of NoSQL databases (including graph and document stores)
- Overview of OLAP and data warehousing

### Course Comparisons
- **CS34800 vs. CS44800 vs. CS44000**
  - **CS34800:** Focuses on application development scenarios (designing and using a database system in web or mobile applications).
  - **CS44000:** Targets data-science and machine learning scenarios, emphasizing large-scale databases.
  - **CS44800:** Concentrates on database system implementation (database internals).

### Course Learning Outcomes
Students will learn to:
- Design effective database schemas that model real-world information semantics.
- Understand different data models (relational, graph, and document) utilized across database systems.
- Pose complex database queries using SQL, NoSQL languages, and theoretical query languages.
- Gain foundational knowledge in indexing.
- Understand transactions and concurrency control.
- Differentiate between OLTP and OLAP databases.
