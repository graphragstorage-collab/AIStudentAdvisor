### Growth Functions
Common growth functions include:
- Constant: \(O(1)\)
- Logarithmic: \(O(\log n)\)
- Linear: \(O(n)\)
- Linearithmic: \(O(n \log n)\)
- Quadratic: \(O(n^2)\)
- Cubic: \(O(n^3)\)
- Polynomial: \(O(n^k)\), where \(k\) is a constant
- Exponential: \(O(2^n)\), \(O(c^n)\), where \(c\) is a constant
- Factorial: \(O(n!)\)

### Important Big-O Relationships
- \(\log_2 n\) and \(n \log_2 n\)
- \(\log_2 n\) and \(n^{1/8}\)
- \((\log_2 n)^4\) and \(n\)
- \(n \log n\) and \(n^2\)
  
### Example: Maximum Subarray
[LeetCode Problem: Maximum Subarray](https://leetcode.com/problems/maximum-subarray/)

Given \(n\) integers stored in array \(S\) of size \(n\), find \(i\) and \(j\) (\(1 \leq j \leq i \leq n\)) such that \(S[i] + ... + S[j]\) is a maximum. 

**Example:**
- Input: \(n = 12\), array: \(4, -7, 4, 0, 5, -8, 13, -2, 4, 6, -6, 2\)
- Maximum sum: \(22\) for \(j = 3\) and \(i = 10\)

### Solutions
#### Solution 1: Find All Possible Solutions
**Procedure:** MaxSum1(S, n)  
- Initialize `max := 0`
- Loop through `i` from 1 to \(n\)
  - Loop through `j` from 1 to \(i\)
    - Initialize `sum := 0`
    - Loop through `k` from `j` to `i`
      - Add `S(k)` to `sum`
      - If `sum > max`, set `max := sum`
- Return `max`
- **Time Complexity:** \(O(n^3)\)

#### Solution 2: Don’t Re-compute
**Procedure:** MaxSum2(S, n)  
- Initialize `max := 0`
- Loop through `i` from 1 to \(n\)
  - Loop through `j` from 1 to \(i - 1\)
    - Update `sum(j,i) := sum(j,i - 1) + S(i)`
    - If `sum(j,i) > max`, set `max := sum(j,i)`
    - Set `sum(i,i) := S(i)`
    - If `sum(i,i) > max`, set `max := sum(i,i)`
- Return `max`
- **Time Complexity:** \(O(n^2)\)

#### Solution 3: Fast Updating (Optional)
**Procedure:** MaxSum3(S, n)  
- Initialize `max := S(1)`, `sum := S(1)`
- Loop through `i` from 2 to \(n\)
  - If `sum > 0`, update `sum := sum + S(i)`
  - Else, set `sum := S(i)`
  - If `sum > max`, set `max := sum`
- Return `max`
- **Time Complexity:** \(O(n)\)
