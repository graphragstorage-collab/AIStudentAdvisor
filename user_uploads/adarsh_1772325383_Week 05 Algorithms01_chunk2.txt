**CS 180 – Algorithms and Complexity 1 – Lecture Outline**

### Algorithm Definitions and Pseudocode
- **Definitions:**
  - **Algorithm:** A step-by-step procedure for calculations.
  - **Pseudocode:** An informal high-level description of an algorithm that uses the structural conventions of programming languages.

### Searching Algorithms
- **Linear Search:**
  - Iterates through each element of the list until the target element is found or the list ends.
  
- **Binary Search:**
  - Efficiently searches a sorted array by repeatedly dividing the search interval in half.

### Sorting Algorithms
- **Bubble Sort:**
  - Repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.
  
- **Insertion Sort:**
  - Builds a sorted array one element at a time by comparing each new element to the already-sorted elements.

### Complexity Analysis
- **Growth of Functions:**
  - Time required to solve a problem is influenced by:
    - Number of operations executed.
    - Size of the input.
    - Speed of hardware and software.
  
- **Big-O Notation:**
  - Used to describe the upper limit of the time complexity of an algorithm, ignoring constant factors and lower-order terms.

### Analyzing Algorithms
- Analyzing algorithm performance involves:
  - Expressing running time as a function of the input size \( n \).
  - Focusing on time and space utilization without actual program execution.

### Example: Finding Maximum in a Sequence 
- **Algorithm:**
  ``` 
  currentMax = s[1]
  k = 2
  while k ≤ n do
    if s[k] > currentMax then
      currentMax = s[k]
    end if
    k = k + 1
  end while
  return(currentMax)
  ```
- **Analysis:**
  - Time of execution is linearly proportional to \( n \).

### Common Growth Functions
- Constant: \( O(1) \)
- Logarithmic: \( O(\log n) \)
- Linear: \( O(n) \)
- Linearithmic: \( O(n \log n) \)
- Polynomial: \( O(n^2) \)
- Exponential: \( O(c^n) \)
- Factorial: \( O(n!) \)

### Big-O Examples
1. Prove \( 60n^2 + 5n + 1 \) is \( O(n^2) \):
   - Show \( 60n^2 + 5n + 1 ≤ 66n^2 \) for \( n \geq 1 \).

2. Prove \( 10n^3 - 5n^2 + 2560 \) is \( O(n^3) \):
   - Show \( 10n^3 - 5n^2 + 2560 ≤ 15n^3 \) for \( n \geq 8 \).

3. Show \( n^2 \) is not \( O(n) \):
   - Assume \( n^2 = O(n) \) leads to a contradiction.

### Complexity Theorems
- If \( f(n) = ak n^k + ak-1 n^{k-1} + \ldots + a_1 n + a_0 \), then \( f(n) \) is \( O(n^k) \).

### Big-Omega and Big-Theta
- **Big-Omega:** Lower bound notation.
- **Big-Theta:** Tight bound where \( f(x) \) is both \( O(g(x)) \) and \( Ω(g(x)) \).
