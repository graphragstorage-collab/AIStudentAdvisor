### Course Description
CS 18200 provides introductory coverage of discrete mathematics tools and reasoning for computer science, including topics such as:
- Logic
- Proof methods
- Functions
- Sets
- Number theory
- Algorithms
- Induction
- Counting
- Probability
- Graph theory
- Finite-state automata
- Regular expressions
- Context-free languages
- Turing machines and computability

### Learning Outcomes
- Application of discrete-math foundations
- Algorithm analysis (Big-O/Θ/Ω)
- Graph-theoretic algorithms to solve complex problems

### Required Text
