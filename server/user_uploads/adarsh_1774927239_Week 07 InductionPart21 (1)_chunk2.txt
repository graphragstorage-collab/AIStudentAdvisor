Full Binary Trees
Definition: The set of full binary trees is
defined recursively by these steps:
• BASIS STEP:  A single vertex r is a full binary.
• RECURSIVE STEP: Assume T1 and T2 are two disjoint full
binary trees. Then, there is a full binary tree T consisting
of
• a root r
• an edge connecting r to the root of the left subtree T1
• an edge connecting r to the root of the right subtree T2.
• Notation: T = T1∙T2

Definition: T o prove a property of the elements of a recursively defined
set, we use structural induction.
BASIS STEP: Show that the result holds for all elements specified in the
basis step of the recursive definition.
RECURSIVE STEP: Show that if the statement is true for each of the
elements used to construct new elements in the recursive step of the
definition, the result holds for these new elements.
The validity of structural induction can be shown to follow from the
principle of mathematical induction.
