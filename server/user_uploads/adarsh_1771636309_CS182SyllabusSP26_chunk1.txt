### Course Description  
This course introduces discrete mathematics tools for computer science, covering:  
- Logic  
- Proof methods  
- Functions and sets  
- Number theory  
- Algorithms  
- Growth functions  
- Induction and recursion  
- Counting and probability  
- Trees and graphs  
- Finite-state automata  
- Regular expressions  
- Context-free languages  
- Turing machines  
- Computability  

### Learning Outcomes  
- Apply discrete math principles.  
- Analyze algorithm complexity (Big O, Θ, Ω).  
- Solve graph-theory problems.  

### Required Text  
- K. Rosen, *Discrete Mathematics and Its Applications* (7th/8th ed.) – student site resources included.
