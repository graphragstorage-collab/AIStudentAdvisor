### Course Description
This course provides an introduction to discrete mathematics tools relevant to computer science. Topics include:
- Logic
- Proof methods
- Functions
- Sets
- Relations
- Number theory
- Algorithm analysis
- Induction
- Counting
- Probability
- Trees and graphs
- Finite-state automata
- Regular expressions
- Context-free languages
- Turing machines
- Computability  

### Required Text
- K. Rosen, *Discrete Mathematics and Its Applications* (7th/8th ed.)  
- Student site includes additional resources like examples, self-assessment, and a proof-writing guide.  

### Learning Outcomes
Students will be able to:
- Apply principles of discrete mathematics.
- Analyze algorithm complexity using Big O, Θ, Ω notations.
- Utilize graph theory and algorithms to solve real-world problems.
