### Course Description
This course covers introductory discrete mathematics tools for computer science, including:
- Logic
- Proof methods
- Functions
- Sets
- Relations
- Number theory
- Algorithm analysis
- Induction
- Counting
- Probability
- Trees/graphs
- Finite-state automata
- Regular expressions
- Context-free languages
- Turing machines
- Computability  

### Required Text
- K. Rosen, *Discrete Mathematics and Its Applications* (7th/8th ed.) 
  - The student site includes examples, self-assessment, and a proof-writing guide.  

### Learning Outcomes
Students will be able to:
- Apply discrete mathematics principles
- Analyze algorithm complexity (Big O, Θ, Ω)
- Use graph theory and algorithms to solve real-world problems
