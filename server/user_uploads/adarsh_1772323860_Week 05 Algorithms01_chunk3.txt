### Key Topics Covered

1. **Definition and Properties of Algorithms**
   - Finite sequence of precise instructions
   - Specified inputs and outputs
   - Correctness
   - Effectiveness
   - Finiteness
   - Generality

2. **Pseudocode Notation**
   - Intermediate representation between natural-language description and concrete programming language
   - Example procedures include:
     - `is_prime(m)` for primality testing
     - `findMax(s, n)` for locating the maximum element

3. **Searching Algorithms**
   - **Linear Search**: Sequential comparison of each array element
   - **Binary Search**: Divide-and-conquer strategy on a sorted array
     - Detailed pseudocode, step-by-step comparison counts, and analysis of iteration complexity:
       - `O(n)` for linear search
       - `O(log₂ n)` for binary search

4. **Sorting Algorithms**
   - **Bubble Sort** and **Insertion Sort**
     - Algorithmic ideas, invariant conditions, pass-by-pass execution
     - Worst-case comparison counts: `Θ(n²)`
     - Pseudocode implementations
     - Visualizations referenced from the USFCA Galles comparison-sort site

5. **Algorithmic Analysis**
   - Discussion of efficiency, number of iterations, work per iteration
   - Identification of thresholds where binary search outperforms linear search (typically > 20 elements)

6. **Cashier’s Algorithm**
   - Greedy method for making change with U.S. coin denominations (quarters, dimes, nickels, pennies)
   - Theorem stating optimality for these denominations and a proof sketch

### Common Growth Functions
- Constant: `O(1)`
- Logarithmic: `O(log n)`
- Linear: `O(n)`
- Linearithmic: `O(n log n)`
- Quadratic: `O(n²)`
- Cubic: `O(n³)`
- Polynomial: `O(n^k)`, where k is a constant
- Exponential: `O(2^n)`, `O(c^n)`, where c is a constant
- Factorial: `O(n!)`

### Important Big-O Relationships
- `log₂ n` and `n log₂ n`
- `n log₂ n` and `n` 
- `log₂ n` and `n^(1/8)` (logarithmic relationships)
- `n log n` and `n²` relationships

### Example Problem: Maximum Subarray
- Link: [Maximum Subarray Problem](https://leetcode.com/problems/maximum-subarray/)
- Given n integers stored in array S of size n, find i and j (1 ≤ j ≤ i ≤ n) such that S[i] + … + S[j] is a maximum.
- Example with n=12: `4, -7, 4, 0, 5, -8, 13, -2, 4, 6, -6, 2`
  - Maximum sum of 22 for j = 3 and i = 10

#### Solution Approaches
1. **Solution 1: Brute Force**
   - Pseudocode: 
     ```
     procedure MaxSum1(S,n)
        max := 0
        for i := 1 to n do
           for j := 1 to i do
              sum := 0
              for k := j to i do
                  sum := sum + S(k)
                  if sum > max then
                      max := sum
        return(max)
     ```
   - Time Complexity: `O(n³)`

2. **Solution 2: Don't Re-compute**
   - Pseudocode:
     ```
     procedure MaxSum2(S,n)
         max := 0
         for i := 1 to n do
             for j := 1 to i - 1 do
                 sum(j,i) := sum(j,i - 1) + S(i)
                 if sum(j,i) > max then
                     max := sum(j,i)
                 sum(i,i) := S(i)
                 if sum(i,i) > max then
                     max := sum(i,i)
         return(max)
     ```
   - Time Complexity: `O(n²)`

3. **Solution 3: Fast Updating (Optional)**
   - Pseudocode:
     ```
     procedure MaxSum3(S,n)
         max := S(1)
         sum := S(1)
         for i := 2 to n do
             if sum > 0 then
                 sum := sum + S(i)
             else
                 sum := S(i)
             if sum > max then
                 max := sum
         return(max)
     ```
   - Time Complexity: `O(n)`

### Problem-Solving Tips
- Fully understand the problem.
- Understand how to solve it manually.
- Develop an initial algorithm, possibly straightforward.
- Critically review your solution and consider improvements.
- Solutions that perform redundant computations can often be optimized.
