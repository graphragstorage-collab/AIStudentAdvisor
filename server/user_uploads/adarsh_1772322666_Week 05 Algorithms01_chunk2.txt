### Introduction to Algorithm Complexity
- The time required to solve a problem is determined by:
  - Number of operations executed
  - Size of the input
  - Speed of the hardware and software
  - Independent of input size

### Big-O Notation
- Represents the growth of functions regarding operations executed.
  
### How to Analyze Algorithms
1. Do not compare execution times directly.
2. Do not count the number of statements executed.
3. Express running time as a function of input size \( n \) (i.e., \( f(n) \)).
4. Analysis is independent of machine speed, programming style, or language.

### Complexity of an Algorithm
- Complexity refers to the time and space required to execute.
- Essential features for performance evaluation include:
  - Time of execution
  - Space used
  
### Example: Finding Maximum Element
- Procedure: 
  ```
  currentMax = s1
  k = 2
  while k ≤ n do
      if s[k] > currentMax then
          currentMax = s[k]
      end if
      k = k + 1
  end while
  return(currentMax)
  ```
- Time of execution:
  - Dependent on the number of iterations (n - 1).
  - Overall time required is linearly proportional to n.

### Growth of Functions
- Week 6.1: Big-O Notation and Common Functions
- Evaluate growth without considering constant multipliers or smaller order terms.
- Example of Big-O:
  - Let \( f(n) = 60n^2 + 5n + 1 \) show it is \( O(n^2) \).

### Examples of Big-O Analysis
1. For \( 60n^2 + 5n + 1 \):
   - Satisfies \( 60n^2 + 5n + 1 ≤ 66n^2 \) for \( C = 66 \) and \( k = 1 \).
   
2. To show \( n^2 \) is not \( O(n) \):
   - Assume: \( n^2 ≤ Cn \), leads to contradiction as no constant can satisfy for all n.

3. Show \( 10n^3 - 5n^2 + 2560 \) is \( O(n^3) \):
   - Satisfied by \( 10n^3 - 5n^2 + 2560 ≤ 15n^3 \) for \( C = 15 \) and \( k = 8 \).

### Growth Functions
- Common functions:
  - Constant: \( O(1) \)
  - Logarithmic: \( O(\log n) \)
  - Linear: \( O(n) \)
  - Linearithmic: \( O(n \log n) \)
  - Polynomial: \( O(n^2) \)
  - Exponential: \( O(c^n) \)
  - Factorial: \( O(n!) \)

### Complexity Categories
- Big-Omega: \( f(n) \) is Ω(g(n)) if \( |f(n)| ≥ C|g(n)| \) for sufficiently large \( n \).
- Big-Theta: \( f(n) \) is Θ(g(n)) if:
  - \( f(n) \) is \( O(g(n)) \)
  - \( f(n) \) is Ω(g(n))
