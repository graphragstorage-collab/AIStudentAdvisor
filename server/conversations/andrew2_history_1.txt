## What to expect from each

### CS 30700 — Software Engineering I
Good if you want practical team-based software development experience.

**Expect:**
- group projects
- software design and engineering workflow
- version control, testing, documentation
- more emphasis on building software than on theory

**Best for:** students interested in internships, industry prep, and large-codebase development.

---

### CS 31100 — Competitive Programming II
Good if you enjoy problem solving and algorithmic speed.

**Expect:**
- difficult programming problems
- strong emphasis on algorithms and implementation
- contest-style thinking
- fast coding under constraints

**Best for:** students who liked data structures/algorithms and want to sharpen technical interview or contest skills.

---

### CS 31400 — Numerical Methods
Good if you like math, scientific computing, or engineering applications.

**Expect:**
- approximation methods
- solving equations numerically
- floating-point/computational error issues
- mathematically grounded programming

**Best for:** students interested in scientific computing, simulation, optimization, or applied math.

---

### CS 33400 — Fundamentals of Computer Graphics
Good if you want visual computing experience.

**Expect:**
- geometric transformations
- rendering concepts
- graphics pipelines
- mathematically heavy material, often involving vectors/matrices

**Best for:** students interested in graphics, game development, visualization, or vision-adjacent topics.

---

### CS 34800 — Information Systems
This is one of the better documented courses in the context.

**Expect:**
- databases and the relational model
- schema design and refinement
- SQL and some NoSQL exposure
- database-backed application development
- transactions and concurrency control
- OLAP/data warehousing overview

From the syllabus context, you should also expect:
- homework assignments
- quizzes
- in-class participation
- a **small database-backed web/mobile application project**
- at least one **lab exam** and two midterms in the Spring 2026 version of the syllabus

**Best for:** students interested in backend development, databases, full-stack work, or data-oriented applications.

---

### CS 35200 — Compilers: Principles and Practice
Good if you want a deep systems/languages course.

**Expect:**
- programming language translation concepts
- parsing, syntax/semantics ideas
- code generation/optimization themes
- challenging implementation details

**Best for:** students who enjoy programming languages, systems, and lower-level software.

---

### CS 35400 — Operating Systems
A classic and usually demanding systems course.

**Expect:**
- processes/threads
- scheduling
- memory management
- synchronization/concurrency
- system-level programming

**Best for:** students interested in systems, infrastructure, embedded/software performance, or serious CS foundations.

---

### CS 35500 — Introduction to Cryptography
Good if you like theory plus security applications.

**Expect:**
- mathematical reasoning
- encryption/signatures/protocol foundations
- proofs or proof-style thinking
- less “hacking,” more formal crypto concepts

**Best for:** students interested in security, privacy, or mathematically rigorous CS.

---

### CS 36100 — Great Issues in Computer Science
Usually broader and less technical than the others.

**Expect:**
- discussion-oriented exploration of major issues in computing
- social, ethical, professional, or historical perspectives
- reading/writing/presentation components may matter more than coding

**Best for:** students who want balance alongside technical courses.

---

### CS 37300 — Data Mining and Machine Learning
Good if you want applied data/ML exposure.

**Expect:**
- models for learning from data
- statistical/computational thinking
- programming assignments with data
- possible math involving probability, linear algebra, optimization

**Best for:** students interested in AI/ML, analytics, and data-driven applications.

---

### CS 38003 — Python Programming
Likely more skill-focused and practical.

**Expect:**
- Python fluency
- scripting and application-oriented coding
- possibly less theory than upper-level core CS courses

**Best for:** students wanting practical coding skill, especially if Python will help with research, internships, or ML/data work.
